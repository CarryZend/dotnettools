About this C# Regex Tester

      
This regex tester is built specifically for .NET developers working with System.Text.RegularExpressions.Regex. Unlike generic online regex testers that use JavaScript or Python engines, this tool accounts for .NET-specific regex features and generates ready-to-use C# code.


      
.NET Regex Features Supported

      
Named groups: Use (?<name>pattern) or (?'name'pattern) syntax. Named groups are displayed in the results table and available in replacement patterns via ${name}.

      
RegexOptions: The flag chips correspond to .NET RegexOptions — IgnoreCase, Multiline, Singleline, and IgnorePatternWhitespace. The generated C# code includes the correct RegexOptions enum values.

      
C# code generation: Get copy-paste ready C# code with proper verbatim string literals (@"..."), RegexOptions flags, and idiomatic patterns for Regex.Match, Regex.Matches, and Regex.Replace.


      
Common .NET Regex Patterns

      
Date matching: (?\d{4})-(?\d{2})-(?\d{2}) — captures year, month, day as named groups

      
Email validation: [\w.+-]+@[\w-]+\.[\w.-]+

      
URL extraction: https?://[\w.-]+(?:/[\w./?&=-]*)?

      
Phone number: (?\d{3})[-.\s]?(?\d{3})[-.\s]?(?\d{4})


      
JavaScript vs .NET Regex Differences

      
While this tool runs in the browser using the JavaScript regex engine for real-time feedback, the generated C# code and pattern documentation reflect .NET behavior. Key differences to be aware of: .NET supports balancing group definitions (?<name1-name2>), inline (?imnsx) options, and RegexOptions.RightToLeft — features not available in JavaScript. For patterns using these advanced features, test directly in your .NET application.
